# ADR-0006 — portable handoff
**Estado:** decisão aceita para planejamento; implementação não autorizada.

## Decisão
G5=B: handoff portátil versionado; continuidade no chat atual, novo chat só se host suportar, fallback exportação.

## Consequências
- Interfaces propostas devem ser verificadas contra implementações reais do SIGA e MCP antes de desenvolvimento.
- Esta decisão não autoriza merge, execução, publicação ou escrita em repositórios observados.
