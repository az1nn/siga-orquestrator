CA03 — Selecionar skill não escreve GitHub nem invoca execução.

CA05 — Host sem novo chat: exportar/copiar handoff; sem fingir navegação.
CA06 — ai-memory read-only, com fontes e isolamento; falha não bloqueia painel.
CA07 — GitHub live prevalece sobre memória e fixtures; parcial/stale explícitos.
CA08 — Somente público e sem persistência de dashboards na V1.
CA09 — Nenhuma tool de escrita no MVP; gateway futuro com aprovação, CAS, idempotência, exact-head e verificação.
CA10 — Alterações deste marco limitadas a branch documental e PR draft; sem merge.
